# X-Plane 737NG Maintenance Toolkit

[![GitHub Release](https://img.shields.io/github/v/release/wahltho/xplane-737ng-maintenance-toolkit)](https://github.com/wahltho/xplane-737ng-maintenance-toolkit/releases/latest)

Download and support repository for the X-Plane 737NG Maintenance Toolkit.
The Toolkit manages aircraft updates, optional patches and components for
supported Zibo and LevelUp installations. Development and builds are maintained
in a separate private repository.

- [Download the latest release](https://github.com/wahltho/xplane-737ng-maintenance-toolkit/releases/latest)
- [Installation and user manual](docs/USER_MANUAL.md)
- [Discord support](https://discord.gg/ySS88PMuyC)
- [X-Plane.org download page and comments](https://forums.x-plane.org/files/file/101018-x-plane-737ng-maintenance-toolkit/)
- [Report an issue](https://github.com/wahltho/xplane-737ng-maintenance-toolkit/issues)

## Installation and updates

Choose the installer or portable package for your operating system. macOS
packages are available for Apple silicon and Intel. Existing managed Toolkit
installations can use the integrated application update function.

The public release address and filenames remain the same. Catalog releases
are published separately as `catalog-v*`; a catalog update does not require a
new Toolkit application release.

## Independence and support

MTK is an independent project by Thomas Wahl (wahltho). It is not an official
Laminar Research, Zibo or LevelUp product. Please direct Toolkit and independent
patch questions to the support links above, rather than official aircraft
support channels.
