# X-Plane 737NG Maintenance Toolkit 0.13.7

Fixes required patch installation after a full aircraft replacement in a folder
with historical patch state. The Toolkit now archives the old patch ownership
with the aircraft-directory backup and establishes new patch backups against
the replacement baseline. Optional module selections are retained separately
and reapplied with the required patches.

Full-directory restore now restores the matching patch state. Older directory
backups without a patch-state snapshot are blocked when managed or pending
patches are present, rather than restoring inconsistent ownership. Unknown
file modifications remain protected; no general hash-check bypass was added.

Validation: 336 .NET tests and five Python tests passed locally. A focused replay
using published S1.50 input files and the actual VNAV v0.2.0, FANS CDU v0.1.6 and
W&B v0.5.3 payloads reproduced the DDS conflict, then verified full replacement,
all three required patches, unchanged repeat and restore. This is filesystem
and engine validation, not simulator flight testing.

No aircraft-package or content-catalog update is required.

Windows x64, macOS arm64 and Linux x64 packages include stable update feeds and
SHA-256 checksums. Windows builds are unsigned; macOS builds are unsigned and
not notarized. This is a Toolkit release, not an official LevelUp aircraft release.
