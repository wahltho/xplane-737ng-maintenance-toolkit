# X-Plane 737NG Maintenance Toolkit 0.28.0

Aircraft patch checks now get their recognition rules from the package catalog. The rules cover VNAV, FANS CDU, Tablet Performance, Weight & Balance, Auto Jetway, CPDLC, VREF, Intentional Fixes, GSE and local 27K/SFP packages. This does not add a 27K/SFP download or change any patch version or default selection.

MTK checks who manages existing patch files and whether their original state can be restored. Matching a downloaded file is not enough to adopt a standalone installation. Unknown or damaged patch markers, foreign companion files and unverifiable backups stop the operation before aircraft files are changed. The checks also run for already-current packages, module selection changes, restore and aircraft updates.

Existing MTK installations with valid state and backups can still be updated and restored. Their original backups are retained. An unselected standalone patch in a separate scope is left alone; patches sharing a file must have a verified restore chain before MTK changes that file.

**Standalone installation remains supported.** This release does not import another installer's backups or update public standalone installers. When switching managers, use the current manager's documented restore or uninstall procedure first, preserving other changes. Do not delete state or backups to bypass a warning.

Catalog 1.16.0 requires MTK 0.28.0. This version includes that catalog and keeps its ownership rules when an older remote or cached catalog is encountered. Saved rules also remain available for offline restore.

Validation: the full .NET suite, Python tests and Mac tests across APFS volumes passed. Public Zibo and LevelUp group packages passed installation, repeat and byte-for-byte restore in isolated file fixtures. States generated with the previous 0.27.0 Core passed reuse and restore with the new Core. These are installer checks, not simulator flight tests. Details: [validation report](https://github.com/wahltho/xplane-737ng-maintenance-toolkit/blob/v0.28.0/docs/validation/ownership-0.28.0.md).

Packages are available for Windows x64, Linux x64, macOS Apple Silicon and macOS Intel x64. Windows builds are unsigned; macOS builds are unsigned and not notarized.
