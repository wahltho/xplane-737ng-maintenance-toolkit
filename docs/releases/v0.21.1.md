# X-Plane 737NG Maintenance Toolkit 0.21.1

The catalog can now offer an optional Intentional Fixes module for Zibo and
LevelUp. Zibo's patch group has no required modules; LevelUp retains VNAV,
FANS CDU and Weight & Balance as required. Intentional Fixes runs last and
applies its CPDLC and LevelUp W&B corrections only when those modules are
selected.

The exact-text handler now accepts a uniquely identifiable installed block
that contains its old anchor, while still rejecting an additional unmatched
old block. Standalone Intentional Fixes state and its legacy signature block
unverified takeover by the Toolkit. The catalog minimum is 0.21.1.

Local validation: 546 Toolkit tests and five Intentional Fixes source tests
passed. Fifteen real Lua composition cases using the production handlers,
including VNAV, AUTO JETWAY, CPDLC and W&B combinations, were idempotent and
passed `luac -p`. Local catalog-source provisioning accepted both product
module contracts. Simulator runtime validation is separate.

The Windows build is unsigned. The macOS builds are unsigned and not notarized.
This is an independent community Toolkit release, not an official Zibo or
LevelUp release.
