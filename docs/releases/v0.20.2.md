# X-Plane 737NG Maintenance Toolkit 0.20.2

This release protects aircraft files and backup history when a standalone patch
installer and the Toolkit have both been used on the same aircraft. Before an
aircraft update, patch install or update, or restore writes files, the Toolkit
checks for known standalone patch state and active patch markers on affected
targets. A detected conflict blocks the operation and identifies the patch and
the next step; the existing aircraft installation is retained.

This is a safety boundary, not automatic import of a standalone installation.
The Toolkit cannot claim a standalone install's original backups as its own.
Standalone packages and the content catalog are unchanged.

Validation: focused mixed-installation regression tests, full automated test
suite, application build and `git diff --check`.
