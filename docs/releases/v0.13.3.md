# X-Plane 737NG Maintenance Toolkit 0.13.3

The LevelUp maintenance panel now displays the group name from the content
catalog (currently “LevelUp maintenance patches”) instead of the VNAV-only
heading. The heading refreshes when the selected aircraft or catalog changes.
Zibo retains its existing VNAV heading.

This is a display-only follow-up to 0.13.2. Catalog 1.7.0 remains bundled;
installation behavior and patch releases are unchanged.

All 322 automated .NET tests pass locally. Platform builds and tests run in the
release workflow for Windows x64, macOS arm64 and Linux x64.
The complete LU 1.51 delta-update workflow still requires an interactive test
against a release candidate.

Packages include stable update feeds and SHA-256 checksums. Windows builds are
unsigned; macOS builds are unsigned and not notarized.
