# X-Plane 737NG Maintenance Toolkit 0.13.8

LevelUp delta-only releases are now discovered automatically while retaining the published full baseline. Fresh installations stage the full baseline and latest cumulative update together, then apply the required maintenance patches automatically. Baseline references and package integrity are validated before installation.

For LevelUp S1.51C, existing S1.50 installations receive the cumulative delta through Check for updates. New installations use the original S1.50 full archive and the S1.51C delta in one staged installation; no replacement full aircraft archive is needed. The three required patches follow automatically.

The release index can reference one older baseline release using `baselineReleaseTag`. Nested references, incorrect baseline versions, invalid manifest hashes and non-older baseline sequences are rejected. Existing full-plus-delta release indexes remain supported.

Validation: 344 automated .NET tests, including delta-only feed discovery, fresh-install planning, current-version detection, invalid references and both aircraft families' staged baseline-plus-delta installation.

A macOS replay with the real published S1.50 full archive and unchanged S1.51C delta verified archive integrity, staged installation, all 66 delta file hashes, all 428 deletions, automatic version detection, all three mandatory patches and an unchanged repeat. Five Python catalog tests also passed. This validates installation and maintenance, not simulator flight behavior.
