# X-Plane 737NG Maintenance Toolkit 0.19.0

Adds generic schema-4 compatibility packages for controlled changes inside a
flat aircraft directory. A package can declare known files to retire and an
exclusive managed scope such as `objects/GSE`. Unknown files, subdirectories,
links and unrecognized file hashes block the operation before aircraft files
are changed. Schema-3 packages remain supported.

The Toolkit verifies the scope before and after applying changes, records
per-file backups, and restores the previous files and original directory
state on uninstall or restore. Repeated installation and repair of a known
reappearing retired file are supported. Catalog groups preserve schema-4
metadata from their source packages.

This release adds the generic package capability; it does not add or publish
a GSE package. The content catalog is unchanged until such a package is
reviewed and released separately.

Validation: the complete automated suite and focused schema-4 transaction,
rollback, restore, adapter and release-cache tests pass. `git diff --check`
passes.
