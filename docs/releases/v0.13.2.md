# X-Plane 737NG Maintenance Toolkit 0.13.2

## Complete LevelUp maintenance follow-up

The LevelUp Update workflow now offers the complete required patch group after
an aircraft update, independently of whether VNAV already appears current.
The same check is available when the aircraft package itself needs no changes.

Confirm **Update patches** to resolve current stable source releases and apply
VNAV Descent Tables, Weight & Balance and FANS CDU, retaining previously chosen
optional modules. Each package is validated before changes are applied.

Deferring, canceling or failing required maintenance now leaves **Required
patches pending** visible. A successful aircraft update followed by incomplete
patch maintenance is reported as partially completed. The LevelUp Update button
remains available for retries. Aircraft and patch transactions keep their
separate backups; a deferred group does not undo the aircraft update.

## Reliable application-update progress

Delayed progress notifications can no longer overwrite the final success,
failure or cancellation state, or interfere with a subsequent download.

Catalog 1.7.0 is bundled; no patch release or catalog change is required.
All 322 automated .NET tests and five Python tests pass locally. Full platform
builds and tests run in the release workflow. The complete LU 1.51 delta-update
workflow has not yet been exercised interactively against a release candidate.

Windows x64, macOS arm64 and Linux x64 packages are provided, with update feeds
and SHA-256 checksums. Windows builds are unsigned; macOS builds are unsigned
and not notarized.
