# X-Plane 737NG Maintenance Toolkit 0.25.0

Start now shows the selected aircraft's update status in one place: installed and available aircraft versions, required LevelUp patches, optional patches recorded as installed, and the last release checks. Zibo patches remain optional. A selected option does not count as installed, and incomplete or failed checks do not report that all versions are current. Patch versions come from Toolkit install records; file validation still runs when you review or apply a package.

Blocked or failed operations now offer **Show result help** and **Export diagnostics** directly on Start. The help explains recognized errors, names the affected file or record when available, and gives the next safe step. It does not assume who changed a file or which installer was used. Diagnostic ZIPs can be anonymized and are saved locally; nothing is uploaded automatically.

Package validation, backups, restore and installation rules are unchanged.

Validation covers missing required patches, installed versus selected optional patches, unknown and differing versions, failed release checks, aircraft selection changes, result help, diagnostics export and the X-Plane process guards. The complete local test suite passed with 746 tests; 6 environment-specific tests were skipped. The Start layout was also checked at small and large window sizes.

Installers and portable packages are provided for Windows x64, macOS Apple Silicon, macOS Intel and Linux x64. Windows packages are unsigned; macOS packages are unsigned and not notarized.
