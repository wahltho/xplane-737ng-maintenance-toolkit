# X-Plane 737NG Maintenance Toolkit 0.17.1

Fixes package and release-channel dropdowns after the remote content catalog is
refreshed or the user changes a selection repeatedly.

- Tool, resource and livery selections now reference the current catalog
  entries after a catalog refresh.
- Package dropdowns keep their complete item lists when switching between
  packages.
- Release-channel dropdowns keep all supported channels and the selected
  channel when switching between packages or reopening the dropdown.
- The fix does not change package contents, catalog policy or aircraft update
  and patch behavior.

Validation: all 490 automated tests pass in Release configuration. A focused
Avalonia UI regression test refreshes the catalog, switches between XLua and
YAL, changes Stable/Beta channels and reopens the affected dropdowns. `git diff
--check` passes.
