# X-Plane 737NG Maintenance Toolkit 0.20.1

Toolkit support is now directly accessible from the persistent header on every
tab through an **MTK support on Discord** button. The X-Plane.org Toolkit page
and its comments remain available beside it. The README, user manual and
X-Plane.org listing also point users to the independent Toolkit support
channels.

This release does not change aircraft updates, package installation, backup or
restore behavior.

Validation: persistent-header UI test, full automated test suite, application
build and `git diff --check`.
