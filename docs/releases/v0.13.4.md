# X-Plane 737NG Maintenance Toolkit 0.13.4

Aircraft updates now install package-supplied VR configuration files
(`*_vrconfig.txt`). Previously, these aircraft files were always treated as
protected personal settings, so the LevelUp V2.S1.50 to V2.S1.51 delta skipped
all five updated VR configurations even on a clean installation.

VR changes appear in the aircraft review and are backed up before replacement.
Existing contents, including personal edits, can be recovered with aircraft
restore. Personal preferences and X-Camera files remain protected.

Validation: 326 automated .NET tests pass locally, including full/delta update
and exact restore with original and customized VR files. An isolated macOS
integration test using the published V2.S1.50 full archive and private V2.S1.51
delta verified all 58 installed payload hashes, all three deletions, the five
ACFs and five VR configurations, required patch installation and an unchanged
repeat. This exercised production installation code; GUI and simulator testing
remain separate. This change addresses VR file handling only.

The existing LU delta and catalog 1.7.0 are unchanged. No LU package rebuild is
needed. Windows x64, macOS arm64 and Linux x64 packages include stable update
feeds and SHA-256 checksums. Windows builds are unsigned; macOS builds are
unsigned and not notarized.
