# Toolkit Content Catalog 1.8.0

Requires Toolkit 0.14.0 or newer for platform restrictions.

Adds optional XLinSpeak for Zibo and LevelUp on Linux x64, using the tool release
manifest from `wahltho/XLinSpeak`. The plugin is installed once per X-Plane
installation at `Resources/plugins/XLinSpeak`. Piper, voice models and audio
configuration remain external prerequisites.

The LevelUp mandatory patch selection is unchanged.
