# X-Plane 737NG Maintenance Toolkit 0.24.0

LevelUp installations on an older or different release can now reach the latest available update without manually installing intermediate versions. When the installed version does not match the cumulative update's baseline, the Toolkit uses the verified published full baseline and the latest cumulative update to prepare a replacement aircraft. An installation matching the baseline still downloads only the cumulative update.

Before applying the replacement, the confirmation shows the packages in order and explains the full backup. Aircraft preferences and local liveries are preserved, verified managed components are retained, and required maintenance patches are checked afterwards. Previously selected optional patches remain selected for reinstallation. Restore brings back the complete previous aircraft and its recorded patch ownership.

Newer local LevelUp versions are not downgraded automatically. An unrecognized installed version requires explicit confirmation of the full replacement. Custom distributions remain review-only, and standalone-patch ownership conflicts remain blocked. The Toolkit rechecks the installed version, distribution and whether X-Plane is running before replacing the aircraft.

Rollback is also more robust if saving the installation state fails after activation: the original aircraft directory is restored before the failed replacement is removed. Read-only preferences or livery files no longer prevent that cleanup.

Validation: independent code review and automated tests cover release selection, downgrade protection, confirmation and cancellation, full replacement and restore, preserved local content, patch ownership, changed metadata, a simulator started during staging, and activation/state-save failures. These checks use small verified test archives; they do not replace an in-simulator flight test.

Installers and portable packages are provided for Windows x64, macOS Apple Silicon, macOS Intel and Linux x64. Windows packages are unsigned; macOS packages are unsigned and not notarized.
