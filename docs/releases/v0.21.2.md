# X-Plane 737NG Maintenance Toolkit 0.21.2

Compatibility packages can now declare `migrate-marked-block-v1` to replace one exact, known older marked Lua block. Missing blocks are inserted at a unique anchor; current blocks are left unchanged. Unknown, modified, partial, duplicate or misplaced blocks stop the transaction before any aircraft file is changed. Older Toolkit versions reject this new operation.

For an already managed file with independent changes, a marked-block migration stops before writing because the historical whole-file backup cannot safely restore those changes. Structural composition by other packages also disables full Restore and Uninstall if independent edits have been incorporated into the managed file. Unchanged managed installations retain their original backup and Restore behavior.

Validation: the full .NET suite passed (555/555), including real planner, transaction, state and Restore tests. The VREF preview package additionally passed five fresh/upgrade/repeat/Restore scenarios for LevelUp and Zibo against the current Toolkit source. Three independently changed prior installations and 40 malformed-marker scenarios blocked without aircraft, state or backup changes. Simulator behavior and live catalog-group combinations remain separate validation gates; this Toolkit release does not activate either preview in the catalog.

This is an independent community Toolkit release, not an official Zibo or LevelUp release.
