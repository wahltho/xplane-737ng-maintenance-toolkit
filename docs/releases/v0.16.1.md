# X-Plane 737NG Maintenance Toolkit 0.16.1

Prepares catalog discovery for the YAL Auto-Unicom Helper and optional LevelUp
liveries.

- Catalog 1.9.0 adds the Windows x64 YAL Auto-Unicom Helper for Zibo and
  LevelUp. Its release manifest requires YAL 4.8b2 or newer, and the Toolkit
  installs or updates that dependency before the helper after confirmation.
- The helper is initially offered on the beta channel because its first public
  release is a prerelease.
- Catalog 1.9.0 also declares the optional Lufthansa livery for the LevelUp
  737-700 and 737-900ER using its published stable 1.0.0 ZIP and manifest.
- A network timeout while checking a catalog livery release is now reported in
  the livery status and operation log instead of interrupting Toolkit startup.
- Catalog 1.9.0 requires Toolkit 0.16.1, preventing older versions from loading
  package metadata whose complete startup path they do not support.

Validation: the complete automated suite passes. The published YAL Auto-Unicom
Helper 0.1.0b2 manifest declares YAL 4.8b2 or newer; its archive, root and
payload hashes match the release metadata. The Lufthansa livery 1.0.0 release
also matches the catalog contract.
