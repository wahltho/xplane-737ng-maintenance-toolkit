# X-Plane 737NG Maintenance Toolkit 0.13.1

This update adds support for upgrading existing FANS CDU v0.1.5 text blocks
to v0.1.6 through the Toolkit. Exact blocks declared by the patch as belonging
to earlier releases can now be replaced in place. Ambiguous or unrecognized
blocks remain blocked.

The LevelUp maintenance group still requires VNAV Descent Tables, Weight &
Balance and FANS CDU. Tablet Performance Calculator and AUTO JETWAY remain
optional. Content catalog 1.6.0 and the existing patch releases are unchanged.

Update the Toolkit before applying FANS CDU v0.1.6 over an existing v0.1.5
installation that requires this block migration.

Windows x64, macOS arm64 and Linux x64 packages are included, together with
VeloPack update feeds and SHA-256 checksums. Windows builds are unsigned;
macOS builds are unsigned and not notarized.
