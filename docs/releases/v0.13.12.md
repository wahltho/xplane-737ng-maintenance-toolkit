# X-Plane 737NG Maintenance Toolkit 0.13.12

This release fixes maintenance-patch migration after an aircraft folder has been replaced with a clean copy while older standalone patch state remains in the Toolkit. If the current target is byte-for-byte identical to a verified recorded original, the Toolkit safely rebuilds the selected LevelUp maintenance modules and retains an exact restore point. Unknown file changes, incomplete active patch chains, and missing or corrupt backups remain blocked.

Fresh aircraft installations now refresh the auto-detected aircraft list immediately, select the newly installed aircraft and display its product information without requiring a Toolkit restart. Linux aircraft folders keep their visible name when the selected path ends with a directory separator.

Validation: 387 automated tests passed in Release configuration, including focused migration, complete install/ownership/restore, fresh-install selection and trailing-separator detection tests. The complete Release solution builds with zero warnings and zero errors. No simulator runtime files or patch payloads are included in this application release.
