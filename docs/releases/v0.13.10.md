# X-Plane 737NG Maintenance Toolkit 0.13.10

Reduces repeated GitHub API requests for maintenance patches by caching release metadata for ten minutes, including across Toolkit restarts. Concurrent checks reuse one response. GitHub rate-limit responses now show when to retry, and patch release queries pause until the indicated time. Package integrity checks remain unchanged.

An existing GitHub restriction can still prevent uncached release checks. Wait until the displayed retry time and run Update again; do not reinstall the aircraft or delete configuration/backups. Expired metadata is not silently used to claim that required patches are current. New patch releases may take up to ten minutes to appear after a successful cached check. No aircraft package or catalog change is required.

Validation: 358 .NET tests passed, including seven new cases for concurrent requests, cache reuse across instances, expiration, corrupt cache recovery, 403/429 cooldown and reset, repository-wide suppression, ordinary permission failures and recovery after network errors. Archive hashes and package validation remain enforced.
