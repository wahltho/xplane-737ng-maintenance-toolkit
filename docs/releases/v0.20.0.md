# X-Plane 737NG Maintenance Toolkit 0.20.0

The app now identifies itself on every tab as an independent project, separate
from the official Zibo Mod. Optional aircraft patches and components are marked
as community packages. Installing, updating, repairing or restoring one of
these packages in a Zibo aircraft requires a separate, initially unchecked
acknowledgement before any files are changed. The confirmation explains that
official Zibo updates may overwrite the files and points to the relevant
Toolkit or Optimized XLua project page for feedback.

Official Zibo aircraft package operations retain their existing confirmation
flow. Package validation, backup and restore behavior are unchanged.

Validation: headless UI acknowledgement and persistent-header tests, full
automated test suite, application build and `git diff --check`.
