# X-Plane 737NG Maintenance Toolkit 0.28.1

The Toolkit now gets its package list and patch ownership rules from the online catalog. The catalog is no longer built into the application. New catalog entries and recognition rules can be published without rebuilding MTK, as long as the installed version supports them.

After a successful check, MTK saves the validated online catalog. If the connection fails, that saved copy remains available for downloaded packages and restore. An older online response cannot replace a newer saved catalog. If neither a valid online catalog nor a valid saved copy is available, aircraft updates and patch actions stay blocked. Aircraft detection and diagnostics remain available; use **Check releases** to retry.

No aircraft release, patch version, required module or default selection changes with this release. Existing MTK state and backups remain in use. Standalone installation remains supported; MTK still requires verified ownership and a complete restore chain before changing existing patch files.

The shared standalone ownership checks also retain unrelated non-UTF-8 Lua bytes and keep installer metadata out of aircraft payloads.

Validation includes the full .NET test suite, catalog downloads and cache handling, startup without a catalog, and blocked install/restore operations without writes. These are installer checks, not simulator flight tests.

Packages are available for Windows x64, Linux x64, macOS Apple Silicon and macOS Intel x64. Windows builds are unsigned; macOS builds are unsigned and not notarized.
