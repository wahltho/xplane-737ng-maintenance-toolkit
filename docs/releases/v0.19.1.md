# X-Plane 737NG Maintenance Toolkit 0.19.1

XLua and other directory-based tool updates now stage and retain rollback
copies outside the aircraft's `plugins` directory. An interrupted operation or
failed cleanup can no longer leave a newly created, plugin-shaped temporary
directory where X-Plane discovers aircraft plugins. The transaction remains on
the same filesystem so directory activation and rollback retain their existing
atomic-move behavior.

Restore now tracks whether the original directory was moved before attempting
rollback, avoiding removal of an untouched target if an earlier step fails.
Backups, package validation, protected scripts and catalog behavior are
unchanged.

Temporary directories left by earlier Toolkit versions are preserved rather
than deleted without verification. With X-Plane closed, move any existing
`.xlua.rollback-*`, `.xlua.restore-*` or `.xlua.stage-*` folders out of the
aircraft's `plugins` directory and retain them until the active `xlua` folder
has been checked.

Validation: focused XLua migration tests and the complete automated test suite.
