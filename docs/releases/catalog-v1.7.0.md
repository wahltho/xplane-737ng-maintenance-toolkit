# Toolkit Content Catalog 1.7.0

Adds **CPDLC FANS PAGES** as an optional patch for Zibo and LevelUp. In LevelUp it
is an optional member of the existing maintenance group, after AUTO JETWAY.
VNAV Descent Tables, Weight & Balance and FANS CDU remain mandatory.

Requires **Maintenance Toolkit 0.13.1 or later**. No new application release is
needed. CPDLC v1.1.0 was verified with the Toolkit engine on Zibo 4.05.35 and
with the complete LevelUp group on V2.S1.50A, including repeat installation and
restoration. Original LevelUp V2.S1 is unsupported and is structurally blocked.

**Existing standalone CPDLC v1.0.0 users:** uninstall v1.0.0 using its own
installer before installing CPDLC through the Toolkit.

**Runtime testing remains pending:** this is filesystem/structural integration
validation, not simulator flight testing. The CPDLC repository's
[RUNTIME_TEST_PLAN.md](https://github.com/wahltho/X-Plane-Zibo-LevelUp-737NG-CPDLC/blob/main/RUNTIME_TEST_PLAN.md)
lists the Hoppie-controller checks.
