# X-Plane 737NG Maintenance Toolkit 0.22.0

Support requests can now include a diagnostic ZIP from **Advanced → Support diagnostics → Export diagnostic package**. It contains a readable report, structured diagnostic data and the current operation log, including package versions, module selections, recorded installation history, file hashes and backup checks. The existing text-log export remains available.

Local paths are anonymized by default. You can keep them when needed for troubleshooting; recognized credentials are removed in either mode. Review the ZIP before sharing it. Export runs locally, makes no network requests and does not change aircraft files, installation state or backups. Aircraft files, backup contents, raw state and settings are not included. Long exports can be canceled.

The report distinguishes missing files, changed recorded hashes and expected absence. Individual file backups are checked against recorded hashes; directory backups are checked for presence only. Hashing has a size limit, and skipped checks are reported. This is a diagnostic snapshot, not proof of simulator behavior or permission to overwrite modified files.

Validation: the full .NET test suite passed (580/580), including privacy, read-only export, damaged backups, unsafe paths, cancellation and the Advanced-screen export controls.

Installers and portable packages are provided for Windows x64, macOS Apple Silicon, macOS Intel and Linux x64.

This is an independent community Toolkit release, not an official Zibo or LevelUp release.
