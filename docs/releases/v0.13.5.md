# X-Plane 737NG Maintenance Toolkit 0.13.5

Fixes required patch installation after a clean aircraft copy replaces an
installation in the same previously managed folder. The Toolkit could block
FANS-CDU with “Managed target changed after installation” because the aircraft
files had returned to their original state while external patch state survived.

The patch planner now accepts files that exactly match their recorded original
size and SHA-256, and missing patch-created files that originally did not exist.
Existing original backups must still validate. Unknown file changes, unexpected
missing original files, and missing or corrupted backups remain blocked.

Validation: 331 automated tests pass locally, including five new regression
cases. Both reinstall cases failed before the fix. An isolated production-code
test using the real VNAV, FANS-CDU and W&B packages verified reinstallation,
unchanged repeat and exact restore of all 13 managed targets. GUI and simulator
testing remain separate; Jochen's individual installation has not been inspected.

No aircraft delta or content catalog change is required. Windows x64, macOS
arm64 and Linux x64 packages include stable update feeds and SHA-256 checksums.
Windows builds are unsigned; macOS builds are unsigned and not notarized.
