# X-Plane 737NG Maintenance Toolkit 0.24.1

New Zibo and LevelUp installations can now use subfolders under Aircraft, such as `Aircraft/Boeing/737NG Series`. The previous restriction to a direct child of Aircraft has been removed. Create the grouping folders first, then enter the complete unused aircraft destination in Install New Aircraft.

The UI and installer use the same destination checks. Existing destinations, paths outside Aircraft, symbolic links and junctions in grouping folders, and installation inside another aircraft remain blocked. The Toolkit prepares the aircraft beside its destination so activation stays on the same filesystem, and rechecks the path and whether X-Plane is running immediately before activation. Existing aircraft can still be selected and updated in their current location.

Validation: automated tests cover nested Zibo and LevelUp destinations, full-plus-cumulative installation, UI controls, invalid destinations, links, changed destinations and failed or canceled staging.

Installers and portable packages are provided for Windows x64, macOS Apple Silicon, macOS Intel and Linux x64. Windows packages are unsigned; macOS packages are unsigned and not notarized.
