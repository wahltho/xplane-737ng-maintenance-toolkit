# X-Plane 737NG Maintenance Toolkit 0.21.3

When an aircraft folder has been moved, scanning its new location can now identify a matching orphaned Toolkit installation history. The Start screen offers **Reconnect moved aircraft history** only when the previous folder is gone, the product matches, every recorded managed file has its expected size and SHA-256 hash, and the original backups are present and valid. Reconnection requires confirmation, saves a copy of the previous `state.json`, and updates the recorded aircraft and restore paths without changing aircraft or backup files.

Ambiguous or changed installations are not adopted. If another Toolkit-managed tool or resource still has ownership at the old location, automatic reconnection remains unavailable rather than partially moving its state. Existing tool state at the new location is retained.

Validation: the full .NET test suite passed (564/564), including move, backup, ambiguity, full-directory history, destination-collision, and Start-screen checks. This is package and state validation; a moved installation on another machine still has to pass its local hash and backup checks.

This is an independent community Toolkit release, not an official Zibo or LevelUp release.
