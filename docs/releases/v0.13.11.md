# X-Plane 737NG Maintenance Toolkit 0.13.11

Aircraft and maintenance patch releases are now checked automatically after startup for the detected product. Installed and available aircraft versions can be compared without pressing Update. Checks do not install anything, reuse the existing patch metadata cache and respect GitHub cooldowns. Disable **Check aircraft and patch releases at startup** in Settings to use manual checks only.

The new **Hardware configurations** section on Start copies saved hardware settings between detected Zibo and LevelUp variants in the same X-Plane installation. Choose an existing source and select destinations. Close X-Plane first. Existing files are backed up, missing files can be created, and **Restore last hardware copy** reverses the copy while protecting subsequent edits. Zibo 2K and 4K share one configuration.

Validation: 381 automated tests passed on macOS, including rendered Avalonia UI tests for automatic version display, persistent opt-out, hardware selection, cancel/confirm and restoration. Native OS click-through was not verified because the UI automation tool could not attach to the test window. No simulator runtime changes are included.
