# X-Plane 737NG Maintenance Toolkit 0.27.0

Start now includes **Installation history & backups**. It shows the actions MTK has saved for your aircraft, package versions and backup locations. Missing backups and dates are clearly marked. Shared X-Plane tools are listed separately. You can refresh the list without changing files or downloading anything.

The history is not a complete log, and finding a backup does not mean it can be restored. This view checks whether backups are still there, but does not open them or verify their contents. Use **Check installation** for file checks and the existing **Restore** buttons to restore a package. Their safety checks still apply.

The new **Quick guide** on Start covers installation, updates, optional patches, file checks, restore and support. Its instructions match the selected aircraft: LevelUp has three required patches; all Zibo patches are optional. Buttons open the full manual, Discord support or the Toolkit download page. The manual now covers both new features.

Aircraft installation, patch selection, backup creation and restore rules are unchanged. The package catalog is unchanged.

Validation: 787 .NET tests and 5 Python tests passed locally; 6 environment-specific tests were skipped. GUI checks covered 980- and 1500-pixel windows, offline operation, unchanged files, cancellation and aircraft selection changes.

Packages are provided for Windows x64, macOS Apple Silicon, macOS Intel x64 and Linux x64. Windows packages are unsigned; macOS packages are unsigned and not notarized.
