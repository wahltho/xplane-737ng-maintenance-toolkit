# Toolkit Content Catalog 1.16.0

Requires Maintenance Toolkit 0.28.0 or newer. Catalog schema 2 adds recognition and ownership rules for aircraft patches. The Toolkit checks existing files, reserved markers, standalone state and restore history before changing aircraft files.

Package sources, patch versions, required modules and optional selections are unchanged. The 27K/SFP entry is a recognition policy only; it is not offered for download or selected in either aircraft group.

Older Toolkit versions reject this catalog and may use their own bundled catalog. Update MTK to receive these checks. Standalone installation remains supported; importing standalone ownership and backups is not included.

This is a catalog release. Application downloads:
