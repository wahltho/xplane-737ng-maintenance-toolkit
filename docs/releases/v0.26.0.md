# X-Plane 737NG Maintenance Toolkit 0.26.0

Expand **Patch versions** on Start to see each patch's installed and available version, whether it is required or optional, and its version status. Beta and preview patches are labelled. Selecting an optional patch does not count as installing it; optional patch selection remains under Advanced.

**Check installation** on Start compares recorded files and individual backups with their sizes and SHA-256 hashes, checks files recorded as absent, and shows the results directly. It makes no downloads or file changes. Missing records, unreadable files, skipped checks and unverified directory contents leave the result incomplete. A passed result applies to the recorded checks, not to every aircraft file or its behaviour in X-Plane. Canceling stops the check, and changing aircraft or starting another file operation clears the previous result.

The user manual now covers both features and corrects older patch descriptions. Aircraft installation, package validation, backups and restore rules are unchanged.

Validation: 773 .NET tests and 5 Python tests passed locally; 6 environment-specific tests were skipped. GUI checks covered the Start controls at 980 and 1500 pixels, offline operation, unchanged aircraft/state/settings files, cancellation, failed release checks and aircraft selection changes.

Packages are provided for Windows x64, macOS Apple Silicon, macOS Intel x64 and Linux x64. Windows packages are unsigned; macOS packages are unsigned and not notarized.
