# Maintenance Toolkit 0.28.2

Fixes a CPDLC installation block caused by a comment which mentions
"intentional fix". MTK previously treated that explanation as a marker belonging
to the Intentional Fixes patch. The installation rolled back.

Catalog rules can now identify an exact explanatory comment which is not patch
ownership evidence. Unknown or damaged patch markers, standalone installations
without verified MTK ownership, changed backups and conflicting saved rules
remain blocked.

The fix covers new installations and existing MTK installations. CPDLC stays
at 1.2.0; its runtime, installer and public package are unchanged. Catalog 1.19.0
provides the comment rule and requires MTK 0.28.2.

See [the comment contract](https://github.com/wahltho/xplane-737ng-maintenance-toolkit/blob/v0.28.2/docs/PATCH_OWNERSHIP_COMMENTS.md) and
[validation results](https://github.com/wahltho/xplane-737ng-maintenance-toolkit/blob/v0.28.2/docs/validation/cpdlc-0.28.2.md).
