# X-Plane 737NG Maintenance Toolkit 0.14.1

Scrolling through maintenance controls no longer moves the selected installation
or progress display out of view.

- The left installation pane and right maintenance pane scroll independently.
- The detected aircraft and full target folder path are shown at the top left.
- A compact progress panel stays at the top right, with status, elapsed time
  and Cancel when cancellation is available.
- The detailed operation log is expandable below the progress panel.
- The user manual explains the new layout. The previously revised X-Plane.org
  description is saved in the repository without further content changes.

Aircraft installation, patch handling and content catalog 1.8.0 are unchanged.

Validation: 421 automated tests passed locally on macOS, including rendered UI
tests at 980×680 and 1180×780 for scrolling, target-path visibility, expanded
logs and long status messages. Release CI also builds and tests on Windows,
macOS and Linux before packaging.

Distribution: unsigned Windows build; unsigned and not notarized macOS build.
