# X-Plane 737NG Maintenance Toolkit 0.14.0

Adds XLinSpeak as an optional tool for Linux x64, available for both Zibo and
LevelUp through content catalog 1.8.0. Installation uses the existing verified
plugin package workflow at `Resources/plugins/XLinSpeak`.

Tools can now declare supported operating systems and architectures. Unsupported
tools are filtered from the list and blocked before release lookup, download,
installation or restore. Existing tools without restrictions retain their
current availability.

XLinSpeak requires a separately installed and configured Piper executable,
voice model and audio output. The Toolkit installs the plugin only.

Validation covers the complete Core regression suite, platform enforcement and
an offline production-engine replay with the exact published XLinSpeak 1.3.1
archive. Linux speech output in X-Plane has not been tested in this integration.

Distribution: unsigned Windows build; unsigned and not notarized macOS build.
