# Content catalog 1.19.0

Adds one exact comment exception to the Intentional Fixes ownership namespace.
The comment comes from the published CPDLC 1.2.0 module; it is explanatory text
and does not indicate an Intentional Fixes installation.

This catalog requires MTK 0.28.2. Older clients reject the new field and keep
their last compatible cached catalog. Publish MTK 0.28.2 before this catalog.

Package versions, group membership, required modules, optional defaults and
installation order remain unchanged from catalog 1.18.0. No CPDLC asset needs
replacement. The 27K and VREF patches remain optional and unselected by default.
