# X-Plane 737NG Maintenance Toolkit 0.16.0

Adds catalog-controlled livery packages as a new optional package type.

- Compatible liveries appear in their own Start-page card for the selected
  aircraft installation, with installed and available versions and actions to
  install, update, verify, repair, open or remove the livery.
- Livery state is scoped to the exact aircraft folder. The same package can be
  managed independently in multiple LevelUp or Zibo installations.
- Release metadata, the ZIP archive and every declared payload file are checked
  by size and SHA-256. Archives are extracted into staging and published with
  rollback protection.
- Normal installation and update never overwrite an unmanaged livery directory
  or a managed livery that has been changed locally. Replacing a changed managed
  livery requires the separate Repair action and explicit confirmation.
- Removal is allowed only while the complete managed directory still matches
  the recorded inventory. Unknown, changed or additional files block removal.
- Livery releases can be checked automatically at startup using the existing
  aircraft and patch release preference. Existing catalogs and package entries
  remain compatible because the new fields and package category are optional.

Validation: 462 automated tests passed. The actual deterministic Lufthansa
livery package was also built locally and passed the Toolkit's complete
install, nine-file hash verification and removal path (128,058,204 uncompressed
bytes). The application build completed with zero warnings and zero errors.

The Lufthansa catalog entry is intentionally not included yet because its
public livery release has not been published. A later catalog-only release can
enable it for Toolkit 0.16.0 without another application release.

Simulator visual validation of individual liveries remains the responsibility
of each livery release. Distribution remains unsigned on Windows and unsigned
and not notarized on macOS.
