# X-Plane 737NG Maintenance Toolkit 0.13.13

This release fixes verified maintenance-patch migration failures in existing LevelUp installations with earlier individual patches and aircraft updates. It corrects state tracking and recovery; it does not change which patches are mandatory or optional.

## Changes

- Preserves individual patch history during unchanged updates and recovers verifiable legacy histories when migrating into the LevelUp maintenance group.
- Reconciles patch ownership for files replaced by aircraft delta updates and restores the matching ownership when reverting a delta.
- Recreates missing backups only when current bytes prove the recorded original; unknown changes and unavailable required originals remain protected.
- Prevents retired standalone patch records from reappearing after migration and adds detailed backup-chain diagnostics.
- Verifies all delta restore backups before writing and rolls back incomplete restore operations.

## Validation

394 automated tests pass. Local macOS replays using released FANS, performance, maintenance-group and S1.51C delta packages passed all four previously failing sequences, including required patch installation, unchanged repeated updates and exact restore. A captured faulty state generated by 0.13.12 was recovered and tested through optional patch enable/disable and restore. Delta restore with an active patch group was also verified. These are installer/engine tests, not simulator flight tests.

## Updating

Install Toolkit 0.13.13, close X-Plane, select the existing aircraft folder and retry the maintenance-patch update. A clean aircraft reinstall is not required for the verified recoverable states. Keep the existing Toolkit state and backups; do not delete them to bypass a blocked operation. If an operation remains blocked, export the log and retain the installation for diagnosis. Missing original bytes cannot be reconstructed when no verified source remains.

## Downloads

- Windows x64: Setup.exe or Portable.zip
- macOS Apple silicon: Setup.pkg or Portable.zip
- Linux x64: AppImage

The release includes VeloPack update metadata and SHA256SUMS.txt. Windows builds are unsigned; macOS builds are unsigned and not notarized. No aircraft patch payloads or catalog policy changes are included in this application release.
