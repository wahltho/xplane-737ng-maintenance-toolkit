# X-Plane 737NG Maintenance Toolkit 0.15.0

Adds general dependency management for Toolkit-managed tool packages and makes
the LevelUp required-patch status on Start reflect the complete required group.

- Tool and aircraft-component manifests may declare optional package
  dependencies with an optional minimum version. Existing manifests and catalog
  entries remain valid without the new field.
- Missing or outdated dependencies are resolved transitively, ordered before
  the requested package and presented together in one confirmation. Each
  package still uses its own validated, backed-up transaction, and later actions
  stop if an earlier dependency fails.
- Dependency planning enforces catalog product and platform restrictions,
  detects cycles and validates stable/beta release availability. Version
  comparison supports conventional versions and project versions such as YAL
  `4.8b1`.
- Installed dependency relationships are stored with package state. Restore or
  downgrade is blocked when it would leave an installed dependent missing its
  dependency or below its required version. Backup restore also restores the
  dependency declarations recorded for that package generation.
- The Start page now reports the LevelUp maintenance group as required patches:
  pending, current or updates available. It also shows how many required
  modules are current. Individual module versions and optional selections remain
  available in Components & Aircraft Patches.
- The Auto-Unicom catalog entry is intentionally not part of this release. When
  added later, it can require YAL 4.8b2 and the content catalog can require this
  Toolkit version so older Toolkit releases do not offer an unsafe install.

Validation: 454 automated tests, including dependency graph ordering, minimum
versions, cycles, platform/product rejection, persisted dependency state,
dependent-safe restore and the Start-page required-patch summary. Release build
completed with zero warnings and zero errors.

Content catalog and patch releases are unchanged. Simulator flight behavior is
outside the scope of these package-engine and UI tests.

Distribution: unsigned Windows build; unsigned and not notarized macOS build.
