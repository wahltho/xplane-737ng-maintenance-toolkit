# X-Plane 737NG Maintenance Toolkit 0.13.0

## Catalog-controlled LevelUp maintenance

The Toolkit now combines patches directly from their existing GitHub releases.
No additional combined patch archive or patch release is needed.

- Required: VNAV Descent Tables, Weight & Balance, FANS CDU.
- Optional: Tablet Performance Calculator and AUTO JETWAY.
- One validated installation plan, per-source version/hash tracking and common
  backup/restore management.
- Existing Toolkit-managed patches migrate only when their recorded backup
  chains can be verified. Unknown or edited files remain protected.
- Zibo retains its product-specific VNAV, AUTO JETWAY and shared tool support.

Requires content catalog 1.6.0, also bundled with the application. Ordinary
source patch updates do not require a new catalog or application release.

## Application update notification

A new stable Toolkit version opens a startup dialog showing current and
available versions. **Update** downloads it and then offers confirmed restart;
**OK** continues using the current version. Settings includes a persistent
startup-check switch, enabled by default, and a manual update-check button.

## Distribution

Windows x64 setup/portable, macOS arm64 package/portable and Linux x64 AppImage,
plus VeloPack update packages and SHA-256 checksums.

Windows packages are unsigned. macOS packages are unsigned and not notarized.
This is an unofficial maintenance utility, not an official Zibo or LevelUp release.
