# X-Plane 737NG Maintenance Toolkit 0.13.6

LevelUp aircraft updates now continue automatically with the required VNAV,
FANS-CDU and Weight & Balance patches. The initial aircraft-update confirmation
explains this follow-up; the separate required-patch confirmation is removed.
Existing optional selections are retained. Completion still requires both stages
to succeed, with existing validation, backups and failure reporting preserved.
Manual package actions and the Zibo VNAV workflow retain their confirmations.

Dump to file now shows a confirmation containing the saved log path and Open
folder / OK buttons. Export errors are shown in a dialog, and logs include the
Toolkit assembly version. A folder-opening error preserves the saved log and
reports its location.

Validation: 330 automated tests pass locally. A macOS UI test using a fresh
published S1.50 installation and the private S1.51B delta completed the aircraft
update and all three mandatory patches after one confirmation, with 65 backups.
The export success dialog, folder opening and deliberately induced export failure
were also verified through the UI. Simulator and Windows UI testing are separate.

These are usability changes; unknown managed-file modifications remain blocked.
No aircraft-package or content-catalog update is required.

Windows x64, macOS arm64 and Linux x64 packages include stable update feeds and
SHA-256 checksums. Windows builds are unsigned; macOS builds are unsigned and
not notarized.
