# X-Plane 737NG Maintenance Toolkit 0.14.2

Fixes maintenance-patch recovery for official LevelUp files with incomplete old
patch/backup history, and populates the Advanced patch list at startup.

- Official S1.50 and S1.51C file contents can establish a verified baseline even
  when old ownership records are disconnected or historical backups are missing
  or corrupt. Recognition requires exact product, path, size and SHA-256 from
  published release manifests; a version label alone is insufficient.
- Current baseline files receive fresh backups before patching. Existing backups
  remain intact, and restore preserves the verified aircraft baseline. Unknown
  changes remain protected; no force-overwrite option has been introduced.
- LevelUp maintenance and optional module checkboxes appear from the catalog at
  startup, without first clicking Update or downloading patch archives. Required
  modules remain selected. Installed optional selections are reflected, and
  choices survive status refreshes and package preparation.
- The module list also works with automatic release checks disabled. Patch
  downloads and validation begin only when an action is explicitly requested.

Validation: 432 automated tests, including actual Avalonia startup/list interaction
and selection tests. Released-package recovery replays cover missing update
history, missing/corrupt old backups, required patch installation, unchanged
repeat, optional selection and exact restore. An unknown object edit still blocks.
The original failure was reproduced before the correction with the same official
cockpit-object hash as the reported 0.14.1 failure.

Content catalog 1.8.0 and patch releases are unchanged. Simulator flight behavior
is outside the scope of these installer and UI tests.

Distribution: unsigned Windows build; unsigned and not notarized macOS build.
