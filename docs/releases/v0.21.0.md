# X-Plane 737NG Maintenance Toolkit 0.21.0

Compatibility-package schema 5 adds conditional targets for catalog groups.
A fix module can now apply a target only when specified functional modules are
selected, without installing those optional functions itself. Referenced
modules must be present in the resolved group and run before the conditional
target. Older Toolkit versions reject schema-5 packages.

Existing schema-3 and schema-4 packages remain supported. The current content
catalog and published patch packages are unchanged; this Toolkit release
provides the capability for a separately released fix package later.

Validation: 542 automated tests, including conditional selection, update and
restore, mixed-schema catalog-group provisioning and reload; Release build and
`git diff --check`.
